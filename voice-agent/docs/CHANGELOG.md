# Changelog

All notable changes to the Buzz voice-agent platform. British English throughout.

## [Unreleased]

### Added
- Repository skeleton following the agreed layout.
- Brand assets in `branding/`: black logo on a transparent background (primary for the platform UI), black on white, white on a transparent background, an icon-only mark and a 64 px favicon. All are derived from the original white-on-black `logo.png`.
- Phase 0 discovery: `docs/PLAN.md`.
- Rebranded Buzz logo, aligned to the BongoHive AI Lab identity: Neural Slate (`#364250`) with a Warm Innovation Gold (`#E8A000`) waveform. Icon, horizontal and stacked lockups in colour, reverse, black and white, as SVG masters plus PNG exports and a favicon. Generated by `branding/build_logos.py`.
- Co-brand lockup placing Buzz beside the BongoHive AI Lab logo (light, dark and transparent versions).

- `infra/inference`: compose for vLLM v0.31.0, Speaches 0.9.0-rc.3, DCGM exporter 4.8.4 and node-exporter v1.12.1, bound to the LAN IP, offline at runtime, Speaches warm-up before vLLM, GPU presets for 16, 24 and 48 GB; model download and digest-lock scripts.
- `infra/app`: our own Dograh 1.49.0 stack with telemetry and cloud calls removed, data services unpublished and the api on loopback; scripted, fail-loud Buzz UI build; nginx TLS template with CSP and blocked internal paths; coturn with a private-address deny list; secret generator.
- `infra/firewall`: default-deny container egress through DOCKER-USER, inbound allow-lists, temporary open-egress for maintenance, systemd unit.
- `infra/asterisk`: Asterisk 22.11.0 built from the checksummed tarball; inbound disclosure before Dograh; `buzz-outbound` compliance guard (suppression check, calling hours, channel limit, disclosure on answer); `buzz-transfer` with staff screening and take-a-message.
- `integrations`: suppression and opt-out service (Zambian numbering plan, hashed decision log, metrics, CSV import, `/v1/redact`); transcript redaction; Dograh webhook template and JSON Schemas; n8n flow design.
- `tools/dograh/configure_providers.py`: idempotent setup of local model providers, the `buzz-local` default and ARI telephony, with `--check` and `--dry-run`.
- `agents/front-desk` (draft): prompt, knowledge placeholder, opt-out, transfer and end-call tools, lint-clean workflow.
- `tests`: workflow linter, 18 front-desk scenarios and validator, packet-capture egress analyser, latency benchmark. `scripts/test-all.sh` runs every offline suite (428 tests).
- `infra/monitoring`: Prometheus, Alertmanager, Grafana (no outbound calls) and blackbox exporter; 30 alert and recording rules with promtool tests; "Buzz overview" dashboard in AI Lab colours.
- `infra/backup`: nightly age-encrypted backups with restore drill, and the 90-day retention job.
- `agents/front-desk/build_prompt.py`: builds the Global prompt from `global_prompt.md` plus `knowledge_base.md` into `workflow.json` (`--check` in `scripts/test-all.sh`). The knowledge block is now filled from bongohive.co.zm (21 Oct 2026).
- `infra/local`: one-Mac stack (Ollama on Metal, Speaches on CPU, no telephony, browser calls on localhost) with `scripts/up.sh` for secrets, model alias, containers, speech models and provider setup. Browser calls relay through coturn via the `turn.localhost` alias; `tools/dograh/import_workflow.py` adds agents without Dograh's cloud.
- `infra/local` tuned for a 16 GB Mac: Qwen2.5 3B at 8k context kept resident, Whisper base.en and a Piper voice (Kokoro took 18 s per sentence on CPU), Speaches limited to 2 threads, Docker VM at 5 GB, and a speech-model warm-up in `up.sh`. Verified with scripted browser-style calls (greeting, speech recognition, knowledge answer, spoken reply).
- Local api patch raising the TTS wait from 3 s to 30 s, so slow Piper sentences are delayed rather than dropped ("TTS context completed with no audio").
- Fixed the local suppression service crash-looping (database path now matches the image's writable directory).
- GitHub Actions CI; `docs/INTERFACES.md`; `docs/TESTING.md`.
